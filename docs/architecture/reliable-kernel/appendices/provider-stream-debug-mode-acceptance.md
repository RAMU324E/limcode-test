# 流式输出调试验收

## 代码证据

| 场景 | 核对结果与边界 |
| --- | --- |
| A01 | 控制器关闭状态十万次判断无文件、定时器；界面十万次调用不加工或发送原文；原版依赖的累计日志未启用。 |
| A02 | 真实普通连接的两个工具、思考、两种完成消息均核验，开关前后模型输出一致；长连接既有协议回归另跑。 |
| A03 | 相同内容仍有不同入口序号与字节范围；不做按内容去重。 |
| A04 | 同一来源追加两次的离线分析测试通过。 |
| A05 | 真实长连接陌生编号被唯一活动工具接收时，保存原编号、实际目标和实际选择分支。 |
| A06 | 分析对照入口完成、实际组装、后端输出、界面确认；未收到界面记录时明确报缺失，不擅自判定界面故障。 |
| A07 | 重建超过二十万字符的未闭合参数，未伪造完成或执行工具。 |
| A08 | 真实长连接失败后切换普通连接，两条路径原文、切换原因及同一请求身份均有测试。 |
| A09 | 复用既有请求、尝试、流代次与物理连接编号；长连接复用及重连回归不变。 |
| A10 | 多事件同块、跨块、中文跨字节与回车换行边界通过真实依赖测试。 |
| A11 | 原文记录位于解析和终止检查之前；解析异常和断流不改写原业务错误。 |
| A12 | 界面真实追加、替换和完成回调有测试；重建带独立模式及快照编号，原有缺口恢复测试通过。 |
| A13 | 中途开启的来源缺口与本地起点分开；起点不冒充历史网络消息。 |
| A14 | 开启时冻结目标，其他对话被拒绝；界面显示实际冻结范围。 |
| A15 | 停止立即拒绝新记录，仅排空已有队列；不调用模型取消接口。 |
| A16 | 8、16、32 兆均实际写到限；时限使用可控单调时钟测试，128 兆及 16 份准入拒绝有测试。 |
| A17 | 单条超大记录在创建完整编码副本之前拒绝，停止取证并标出缺失。 |
| A18 | 索引写失败、清单发布失败及容量拒绝测试通过；真实硬盘写满不作破坏性实验。 |
| A19 | 独立子进程分别在原文、索引、清单同步后强制退出，新实例仅承认已发布且校验通过的前缀。 |
| A20 | 绑定失效后不向旧路径写入，释放文件句柄并标记未正常封存。 |
| A21 | 多面板、命令重放、旧停止命令、关闭中开启与重启后默认关闭均有控制测试。 |
| A22 | 分析器只有文件只读入口、校验和普通数据解析，没有网络或工具执行依赖；不会重放记录里的命令。 |
| A23 | 仅删除固定命名且内容受管的选定目录；读取占用和活动记录不能删除。 |
| A24 | 记录与分析的扩展版本、提交与关键模块摘要均用于对照；无法读取的摘要不宣称版本相同。 |
| A25 | 包内容及来源由发布检查处理；本轮任务是打包推送，不覆盖本机现用扩展，编辑器安装及重开设置不宣称已验收。 |
| A26 | 等长但不同的实际片段被保留，离线分析指出与入口不一致。 |
| A27 | 活动记录、读取中记录禁止清理，导出目标不覆盖已有目录。 |
| A28 | 修改默认预算不改变本次预算与截止时间；同目标重复开启返回原记录。 |

## 检查入口

- `npm run check:local`：本地代码、界面类型、合同与可靠内核回归。
- `npm run check:plan:tracked`：提交后核对已跟踪内容。
- `tests/reliable-kernel/debug-capture-*.test.mjs`：本功能来源、控制、写盘、分析及界面观察测试。
- `tests/openAIResponsesWebSocketSession.test.cjs`：长连接协议及实际错误归属观察。
- `scripts/playwright/debug-capture-fixture.mjs`：真实设置组件与模拟宿主的浏览器检查，不连接付费模型或真实聊天数据库。
- 每个平台安装包另做压缩包完整性、运行文件范围、提交来源及关键模块摘要核验；发布结果以对应版本的发布资产和远端检查记录为准。

本验收不是对历史参数无限增长故障的根因裁决。客户端入口前的重复可能来自模型或中转服务，仍需服务端证据才能继续区分。
